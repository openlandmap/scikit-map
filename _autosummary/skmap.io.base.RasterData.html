Generates an animation with the given band(s) and saves it.

Parameters:

  • cmap (str) – colormap name that will derived from matplotlib.colormaps()

  • groups (list) – used to select the band(s) or to generate a composite image that will be used as animation frame. Default is None, which selects the first band on RasterData.

  • scaling (float) – scaling can be used to increase/decrease the frame size. Default is 2.

  • cbar_title (str) – title for the colorbar.

  • img_title_text (str) – title text for each frame, or "index".

  • img_title_fontsize (int) – font size for the image title.

  • vminmax (tuple) – (vmin, vmax) tuple for clipping.

  • interval (int) – frame interval in milliseconds.

  • to_gif (str) – path to save a GIF if not None.

  • n_jobs (int) – number of parallel jobs.

filter_date(start_date, end_date=None, date_format='%Y-%m-%d', date_overlap=False, include_non_temporal=False, by_start_date=False, return_array=False, return_copy=True, return_idx=False)[source]#

Return a copy keeping only layers whose date falls within [start, end].

Parameters:

  • include_non_temporal – when True, also keep layers without a date (static layers with None in the start-date column), so they are preserved alongside the date-filtered temporal layers.

  • by_start_date – when True, a layer is kept when its start_date falls within [start_date, end_date] (the end_date column is ignored). This assigns cross-year composites (e.g. a Dec-to-Mar winter composite) to the year they start in.

classmethod from_info(info, backend='numpy', verbose=False, date_format='%Y%m%d', ignore_29feb=True)[source]#

Build a RasterData from a pre-built info DataFrame (classmethod).

Used by the layer sources (skmap.io.sources) to construct a lazy RasterData whose info already carries dates, groups, names and any extra per-layer variable columns. Unlike __init__, the incoming temporal column is preserved as-is (static layers stay False).

classmethod from_stac(url, collections, datetime=None, bbox=None, bands=None, max_items=None, limit=500, date_format='%Y%m%d', ignore_29feb=True, backend='numpy', verbose=False)[source]#

Build a lazy RasterData from a STAC catalogue (classmethod).

Queries the per-collection /items endpoint and yields one info row per data asset (roles contains "data"). The result holds remote COG hrefs + dates only (no .read()); its info carries collection, asset, year, gsd and epsg columns. See skmap.io.sources.StacSource for the query rules.

classmethod from_yaml(path, base_path=None, date_format='%Y%m%d', ignore_29feb=True, backend='numpy', verbose=False)[source]#

Build a lazy RasterData from a YAML layer catalogue (classmethod).

See skmap.io.sources for the YAML schema and the expansion rules. The result holds paths + dates only (no .read()); its info carries one column per {variable} referenced in the path templates (e.g. band, year, start_month, end_month, perc) so runners can group by multiple columns.

point_query(x, y, cols=3, titles=None, label_xaxis='index', return_data=False)[source]#

Makes point queries on dataset and provide plots and data

Parameters:

  • x (list) – longitude value(s) of the given point(s)

  • y (list) – latitude value(s) of the given point(s)

  • cols (int) – column count of the desired layout. Default is 3.

  • titles (list) – list of the titles that will be placed on top of the each graph

  • label_xaxis (str) – labels of the x axes. it could be index, name,`date` or None.

  • return_data (bool) – If the user wants to access the data sampled from rasters, this needs to be set to True. Default is False

Examples

>>> import geopandas as gpd
>>> from skmap.data import toy
>>> rasterdata = toy.ndvi_rdata(gappy=False)
>>> points = gpd.read_file('./skmap/data/toy/samples/samples.gpkg')
>>> rasterdata.point_query(x=points.geometry.x.to_list(), y=points.geometry.y.to_list() , label_xaxis='index', cols=3, titles=points.label)
read(extent=None, extent_epsg=None, dtype='float32', expected_shape=None, overview=None, ram_fraction=0.7, n_jobs=4, scale=1, gdal_opts={})[source]#

Read the selected layers into a SharedArray and return self.

Parameters:

  • extent (list) – (minx, miny, maxx, maxy) bounding box to read, in extent_epsg (defaults to the rasters’ own CRS). None reads the full extent.

  • extent_epsg – EPSG code / CRS of extent. Defaults to the rasters’ own CRS.

  • overview (int) – COG overview factor to read (e.g. 2). None auto-selects: if the full read would not fit in RAM (estimated from width, height, dtype and ram_fraction of available memory), the finest overview that fits is used and logged.

  • ram_fraction (float) – fraction of available RAM the read is allowed to use (default 0.7).

Side effects: sets self.window, self.overview, self.extent, self.extent_epsg, self.base_raster and self.array.
